# Design System Audit

1. Inspect active routes, existing components, global styles, tokens, repeated visual patterns, and current references.
2. Separate intentional repeated patterns from incidental one-off details.
3. Decide whether to reuse, consolidate, create a portfolio primitive, or assess an external system.
4. Define states, accessibility, responsive behavior, owner, and visible reference coverage for every shared primitive.
5. Do not import Hito DS or another external system without a compatibility and ownership decision.

The goal is a small maintainable shared language, not a large component inventory.
