# Plan Writing And Closeout

1. Start from current verified behavior and the last accepted or failed gate.
2. State the outcome, owner, boundaries, risks, and evidence needed to close each step.
3. Keep implementation mechanics with the execution owner, not in the plan.
4. Update active status only after evidence supports it; archive only completed or explicitly superseded work.
5. Do not add history entries for private micro-cleanups without durable product meaning.

Plans, current-state documents, and task records change only when durable product or workflow truth changes.
