# Architecture Audit

1. Establish the active runtime and content path before reading legacy code.
2. Map the canonical owner, consumers, and source-of-truth documents.
3. Separate demonstrated duplication from intentional domain-specific variation.
4. Recommend deletion, consolidation, or one bounded next owner only when reachability supports it.
5. Keep plans concise: outcome, boundaries, risks, evidence, and one next owner.

Architect does not implement another owner's code by default.
