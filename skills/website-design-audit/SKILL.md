# Website Design Audit

Audit:

- first impression
- hierarchy
- typography
- spacing
- section rhythm
- visual density
- CTA clarity
- responsive risks
- consistency with the design system

Output:

1. What works
2. What fails
3. Root cause
4. Recommended direction
5. Non-goals
6. One admitted next owner/action, using the existing Notion Task

Handoff rules:

- Follow `docs/process/agent-workflow.md`: update/read back the Task and send its link directly to the verified next owner when authorized; do not make Ivan copy a prompt.
- New designs require Ivan's approval before implementation handoff.
- Only if Ivan explicitly asks for a prompt, write one English `ROLE: <ROLE>` packet using the shared template. Do not generate a chain.
