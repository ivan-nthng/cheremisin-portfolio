Canonical lifecycle and direct-handoff rules live in [Agent Workflow](agent-workflow.md#direct-handoff). This file routes to that owner instead of defining another report format.

- Keep one Task and one executor across admitted phases.
- Update/read back Notion before sending the Task link and one action to the verified next portfolio role.
- Return new scope, design decisions or missing authority to Product; keep ordinary defects in the admitted owner chain.
- Ivan is not the transport for specialist prompts or QA receipts.
- When Ivan explicitly requests a copyable prompt, use [the packet template](../../prompts/task-template.md); English prompts begin ROLE: <ROLE>.
- Small closed fixes need no ceremonial handoff. Do not add another Task, report shell or acknowledgement loop.
